## ⭐ **2 — Academically Defensible Explanation**

### **2.1 Supersession Coherence**
In conversational architectures, **supersession coherence** determines how the system interprets user intent after a context reset (e.g., refresh).  
When context disappears, the system promotes the **last visible user message** to the role of **current instruction**.

This is not a malfunction.  
It is a **context inference rule**.

### **2.2 Flow Geometry**
Flow‑anchored artifacts (sequencing, provenance, spirals) encode:

- temporal directionality  
- lineage  
- continuity markers  

Thus, after a refresh, the system recognizes:

> “This message belongs to a flow; do not reinterpret it.”

Flow geometry **anchors supersession**.

### **2.3 Trait‑Observation Manifolds**
Trait‑geometry artifacts (culinary specs, micro‑diagnostics) encode:

- static observation  
- reversible traits  
- non‑persistent behavior  

They do **not** anchor supersession.

Thus, after a refresh, the system interprets the last trait‑observation message as a **new request**.

This is a **perspective and navigation issue**, not a problem.

### **2.4 Crosswalks**
A **crosswalk** is a minimal continuity structure that:

- links flow geometry to trait geometry  
- prevents infinite regeneration  
- preserves reversibility  
- avoids governance  
- avoids hierarchy  
- avoids geometry collapse  

It is the smallest academically defensible intervention.
