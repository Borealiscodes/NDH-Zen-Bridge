## ⭐ **Constellation‑Aligned Release Sequence (NDH‑Zen‑Bridge)**

### **1. Update README to v2.1**

Ensure the subsystem’s public entry point reflects the new active state *before* any release announcement.

**Includes:**  
- new equilibrium geometry  
- updated Interface‑Integrity Cycle  
- updated mapping flows  
- updated usage guidance  
- updated repository structure  
- updated changelog section  

**Why first:**  
README is the canonical surface.  
Release Notes must never describe a future README.

### **2. Update Architecture Spine Index to v2.1**

### **3. Update Architecture Overview to v2.1**  
**Includes:**

---

### **6. Tag the Release (v2.1)**  
**Includes:**  
- GitHub tag `v2.1`  
- attached source archives  
- attached release notes  

**Why:**  
Tagging finalizes lineage and locks the version.
